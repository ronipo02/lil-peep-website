# Мій перший сайт
# Lil Peep — Фан-сайт

## Мета проєкту

Цей сайт присвячений американському музиканту Lil Peep, його творчості та впливу на сучасну музику. Мета проєкту — створити невеликий фан-сайт з інформацією про артиста, фотографіями та сторінкою контактів.

## Використані технології

- HTML5 — для створення структури сторінок.
- CSS3 — для оформлення та дизайну сайту.
- Git — для збереження історії змін.
- GitHub — для зберігання коду проєкту.

## Як перевірити сайт

Відкрийте файл `index.html` у браузері. Перевірте роботу навігаційного меню, відображення фотографій та перехід на сторінку `contacts.html`.
